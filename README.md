# Pruebas TDD - API de Inventario

## Descripción
Este proyecto implementa pruebas siguiendo la metodología TDD (Test Driven Development), enfocadas en validar el correcto funcionamiento de una API de inventario.

TDD es un enfoque de desarrollo donde primero se escriben las pruebas y luego el código necesario para hacerlas pasar, garantizando mayor calidad y confiabilidad del software.

## Metodología TDD
El proceso seguido se basa en el ciclo:

1. 🔴 Red: escribir una prueba que falle  
2. 🟢 Green: implementar el código mínimo para que pase  
3. 🔵 Refactor: mejorar el código manteniendo las pruebas  

##  Tecnologías utilizadas
- Python   
- Java script

## Tipos de pruebas implementadas
- Pruebas unitarias  
- Validación de lógica de negocio  
- Pruebas de endpoints 

## Casos de prueba
Se validan escenarios como:

- Creación de productos con datos válidos  
- Validación de datos inválidos  
- Consulta de productos  
- Actualización de información  
- Eliminación de registros

## Resultados esperados
- Ejecución exitosa de todos los casos de prueba
- Validación de comportamiento esperado del sistema
- Detección de errores en entradas inválidas
- Evidencia

Se incluyen archivos con los casos de prueba documentados:

- Casos de prueba en Python
- Casos de prueba en JavaScript
- Objetivo del proyecto

Aplicar la metodología TDD utilizando diferentes tecnologías, con el fin de mejorar la calidad del software y garantizar la correcta implementación de funcionalidades.
